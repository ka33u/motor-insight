# 退料与库存状态核对

入口：库存与物料保障 → 退料与库存状态；查找 `MO-260928-Q` 可阅读47号模拟Excel的7张工单、8笔退料和7个目标库位。工作簿含135行、9张业务表及导入说明，包含两个独立配置及完整BOM和路线。

## 三种证据并列阅读

单据关联沿用生产领退料核对：原领料身份、工单、物料、批次、严格先后及累计上限必须一致。该结果不代表检验合格。

退料时状态读取截至退料发生时点的目标库位台账。退料与状态变更同刻、之前有同刻多次变更、前序台账有问题或缺少期初时，显示待核对；不按单号排序推定实际先后。之后的新事件不倒改原时点状态。

当前库位证据检查截至固定业务时点的完整收发与状态链。原领料库位有问题会传递到退回库位；同刻多次状态变更不能按单号形成确定状态。原登记状态仍在明细保留，但可核对状态和可用量留空。待检、冻结、隔离和待退货的已知可用量为0；未知与0分别显示。

这是对已导入库存状态登记的核对。批准工号只是原登记字段，尚未建立逐退料检验报告或批准授权有效性的证明，不构成平台质量批准、实物释放或真实库存承诺。本页不会改写原库存与备料算法；有额外时序歧义时，本页结果另行留空，不替换旧指标。

## 数量与范围

- 退料笔数按库存退料流水统计；单据可核对、退料时状态明确、当前证据可核对分别计数，分母均为所选范围内退料笔数。
- 单据退回量按原计量单位汇总；同单位有无法核对的单据时，该合计留空，原始数量仍在明细保留。
- 目标库存按**物料×批次×库位**去重后汇总；同一库位有两笔退料时，余额只计一次。筛选工单或退料只选择目标库位，不裁剪该库位的其他收发。
- 库位可含期初、其他退回及后续领用，其余额不能分摊为某笔退料的剩余量。kg与件分开，当前余额不沿日期累计。
- 上方图表和数量表使用完整应用范围；下方状态按钮筛选清单与完整导出。“有证据待核对”可与当前可用、受限状态重叠。例如退料时顺序未知，但当前状态已明确。

## 明细、来源与导出

每笔退料可展开原领料，以及原库位和退回库位的期初、完整截止内收发、运行余额、状态登记、批准工号与原因。若相关库位存在采购入库，来源还保留到货、来料检验、采购行与供应商依据。所有来源追到Excel文件、工作表和行号，原件下载沿用管理员权限。

六类演示岗位均可读取不含价格、人员成本的核对。CSV导出当前筛选的完整退料清单、去重目标库位及完整来源，不因分页缩小；范围、来源或规则版本改变后旧回执失效。成功导出记录最终响应文件摘要，业务事实不变。关闭或替换弹窗、切页后，不采用迟到的明细响应。

本轮以Excel逐值与类型核对、独立数量复算、公开空库回放、服务端回归、纯JS状态检查和六岗位原生HTTP核对验证。浏览器布局、手机、键盘和实际浏览器下载仍待验收。线边实盘、借料、调拨分配、逐退料检验及正式授权、在制剩余物料与工序重排仍待建设。
