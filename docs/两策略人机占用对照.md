# 两策略人机占用对照

v0.29.0 在“联立试排 → 并排比较两种派序”新增“人机占用对照”。计划人员可以核对同一设备或工号在两种策略下安排了哪些批次、何时换型加工，再进入原任务依据。全部来源仍为正常导入的合成 Excel。

## 定义

| 项目 | 口径 |
|---|---|
| 对象范围 | 两列已排任务中设备资源位或工号的并集；未使用的候选对象不在图中 |
| 横轴 | 同一方案时间范围，或两策略全部已排任务的最早准备开始至最晚完成；两列、两种视角、筛选及分页始终共用同一范围 |
| 占用 | 原任务的准备开始至完成，包括换型与加工；按原对象分别相加 |
| 换型 / 加工 | 加工开始减准备开始 / 完成减加工开始；分钟仅显示两位小数，原时点完整保留 |
| 占用差值 | 批次优先级优先减应完成时间优先；不是效率或损失 |
| 安排变化 | 任务编号、准备/加工/完成时点、设备或工号任一变化；分钟差值为0仍可能有安排变化 |
| 未安排 | 一列无本对象任务时明确说明；未排任务不绘为零时长；原对照暂停时不产生占用结果 |
| 时间语义 | 延续原工厂本地假设时间，只用统一坐标计算，不因浏览器时区转换时间 |

先验证完整任务数、任务/批次身份、两列原摘要、时间顺序及范围、换型加工分钟，再核对同一人机在每种策略内无重叠。校验不通过时暂停新占用图，原始任务清单仍可核查。

设备和人员是同一排程的两种阅读视角，不能相加。每种策略只加自己实际安排的任务；两列不相加为产量。没有可用窗口分母，不计算设备利用率或人员绩效。图上的空白没有核对候选、资格和可用窗口，不能据此插单。

## 呈现与交互

- 每个原编号上下两行，固定策略名称和颜色；浅色换型、深色加工。旁列任务数、占用及分段分钟。
- 可切换设备/工号、选择对象、只看安排变化，每页8个对象。范围切换对全部对象同时生效，翻页或局部筛选不缩放。
- 点占用段读取该任务的原两策略详情；小区段可用“查看两列相关任务”进入任务清单，避免只能点细线。
- 点对象后清除旧物料/批次限制，保留左右任一列匹配该原编号的任务；随后手动批次、变化条件取交集。“重置为全部任务”清除全部局部限制。
- 切换阅读页保留占用视角和范围，重新读取重置；旧异步任务详情不覆盖新的选择。
- 顶部批次汇总、共同来源和完整 CSV/JSON 保持全方案。JSON 的 `comparison` 交由同版 `occupancyReport` 可零数据库查询复原图；CSV 保留原任务时点。局部选择不生成局部导出。

## 验证边界

纯 JS 手算与正常 Excel 夹具检查包含同资源相邻任务、人员跨设备冲突、两侧对象并集、无安排、原摘要缺失、身份重复、数量变化筛选、稳定时间轴、下钻、重置、转义及异步竞争。六岗位隔离 HTTP 将完整导出的原任务时点独立汇总，与实际 JS 投影逐对象核对；来源行按归档 Excel、工作表和行号检查。

无新业务输入、迁移、排程算法或正式批准。沿用 v0.27.0 的43份有效 Excel 公开回放库；主库232,941条事实及原件保留。当前验证详情见 `demo/validation.json`。浏览器布局、键盘、手机及实际下载仍未验收。
