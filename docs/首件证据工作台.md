# 首件证据工作台

入口为“首件证据”。投产条件页可打开所选方案的同工单候选首件对照。

本功能复用已正常导入的工序检验与计量Excel，未新增、修订或批准业务记录。最新非作废检验先选定再校验，不能因最新记录缺项而退回旧合格记录。

## 粒度与核对

一个首件应检计划一行；巡检不计入本页。业务及登记截止均为合成数据截止 `2026-10-01 18:00:00`。原始实测与规范按当前导入内容重放，不宣称还原当时数据库历史。

互斥主状态依次为：检验资料待核对、到期待检/尚未到期、实测有超限、必检有漏项、计量依据待核对、所列证据齐备。明细仍同时保留超限、漏项和计量问题，因此问题项数不能相加作为计划数。作废、首次、最新、未来检验分别保留或排除；历史非作废记录的资料问题仍要求核对。

“所列证据齐备”要求最新实测齐项且在模拟限值内，并且每项所列计量登记适用或明确不需要校准登记、未命中当前登记影响范围、无计量资料问题。仪器使用系列全版本读取；变更身份、校准撤销、登记失效或已知影响不能被较早的正常记录覆盖。

当前演示有288个首件计划：219个所列证据齐备、17个待检、19个实测超限、12个漏项、13个计量依据待核对、8个检验资料待核对，涉及32个工单和529项最新实测。这是计划级证据状态，不是合格率、放行率或台数。

## 两个阶段

开工准备登记回答能否准备试制。首件实测在执行后形成，用于授权人员复核放量依据；本功能未实现正式批准。

投产方案按每条开工质量条件，严格匹配同工单、同配置、同路线版本、同工序分支的首件计划。现有10个方案各66条条件均未找到对应首件计划，因为其工单尚未开工；不能借用历史工单首件证明新工单。此表不判断各工序首件是否必须，也不新增或强制首件计划。未来即便找到候选，仍需核定设备、批次、换型和首件触发范围，不能自动推导覆盖。

## 呈现与来源

顶部七类主状态按当前筛选汇总，始终标明全库计划数；按计划、工单、配置、批次和工序查询。投产候选对照始终使用所选方案全部质量条件，不随历史计划筛选变化。

明细同时显示最新数值与模拟限值、仪器与使用登记、测量时校准登记、已知影响、检验履历、漏项及Excel文件/工作表/行号。CSV提供当前范围清单，JSON提供明细及完整受控计算来源；来源索引不授予原件访问。

读取凭据绑定来源、规则、筛选及当前账号，600秒过期；数据、版本或权限变化后须重新读取。仅导出追加审计，读取不改变业务事实。六岗位可读取历史首件证据；投产方案依据仅管理员、经营分析师、生产计划员可读。导出不包含价格、成本字段。

## 边界与后续

真实证书原件、测量能力验证、复核签字、首件触发批次覆盖、正式首件批准和放量执行仍需建设。计量核查的“资料核对已登记”不是消除产品影响或批准。未接真实U8/MES，未写回工单或检验结论。最新页面未完成浏览器、手机及实际下载交互验收。
