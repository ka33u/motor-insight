测量系统交叉采样：数据定义与BI呈现（2026-10-07）

适用本厂：多配置、小批量定制电机。用友U8与待上线的momo MES接口尚未接入。这里全部使用独立合成采样，不把生产复测直接视作MSA。

本专题回答三个问题：采样是否完整；变异分别来自重复测量、操作员、样件与人员交互及样件间差异多少；每个读数和计算条件来自哪行Excel。入口 #msa。它支持试验设计和数据核对，不生成MSA资格、人员责任或产品批准结论。

来源文件：35_测量系统交叉采样_模拟.xlsx。
三个独立数据集：msa_studies（11个试验）、msa_members（141个样件/人员成员）、msa_observations（930条逐次观测）。总计1,082行。SN与员工编号使用现有模拟台账；每个试验另有稳定编号、盲测标签和声明成员，不用普通终检编号冒充重复观测。
主要计划为10样件×3操作员×3次，每个交叉单元计划3条。采样顺序使用固定随机种子并记录实际登记序号；这只是模拟盲测和随机性，并不证明真实试验独立。
每条观测保留试验、样件成员、操作员成员、轮次、登记序号、原数值、原单位、方法版本、实测时间、登记时间、温度、状态、依据及备注。时间为工厂本地时间。零值与缺测分开。跨成员引用、重复SN/人员、重复轮次与未知时间均核查。

11个可复核场景：
MSA2609-0001 完整采样，90条。
MSA2609-0002 重复测量波动，90条。
MSA2609-0003 操作员均值差异，90条。
MSA2609-0004 样件与人员交互，90条。
以上4个可进行合成候选试算。
MSA2609-0005 缺少一条，89条；完整性矩阵列明缺少轮次，不补零。
MSA2609-0006 同轮次多登记一条，91条；显示全部重复资料，不择优删行。
MSA2609-0007 单位不统一，90条；原数值及单位保留，不自动换算。
MSA2609-0008 二值旋向，90条；保留0/1计数，不使用连续ANOVA。
MSA2609-0009 全部零变异，90条；方差百分比不适用，不能解释为理想测量系统。
MSA2609-0010 单操作员，30条；不能据此估计当前交叉模型的再现性。
MSA2609-0011 校准登记未覆盖试验，90条；不退回更旧登记生成合格结果。
以上7个试验暂停，资料及缺口仍可查。

BI展示从计划和条件开始：
1. 页面顶端显示试验、配置、规范、仪器、单位、方案/方法版本、开始结束与业务截止。换试验才换数据范围，不按页面筛选删成员后重算。
2. 四张摘要只报告登记/计划、声明因子、字段可用/待核对、待核对交叉单元。字段可用不等于整体试验适用。
3. 样件×操作员矩阵，每格显示登记数/计划数，点选查看全部轮次，缺测与重复分别列出。
4. 显示校准登记所引版本及是否覆盖整个试验窗口。登记适用不证明真实校准证书或测量能力。窗口内校准变化须拆分试验；未来登记不能倒推当时已知依据。
5. 交互均值图的横轴为样件类别，线为每个操作员单元均值，点为全部重复读数。它不是生产时间趋势或SPC图。线条差异不能自动归因于操作员责任。
6. 方差占比与研究变异占比分开绘图；再现性、GRR和总变异列为合计项，不重复累加。公差占用另列，只有双侧、同单位公差核实时才算。
7. ANOVA明细保留平方和、自由度及均方。方差分量表同时显示原始矩估计与呈现值，负估计保留并将呈现值截为零，不按P值筛选交互。
8. 全部成员均值、逐条读数、暂停原因和Excel行来源可查。列表翻页不会改变计算、图形或CSV总体。

计算契约：MSA-CROSSED-FULL-TRIAL.01。
平衡交叉随机效应模型 y = 均值＋样件效应＋操作员效应＋样件×操作员交互＋重复误差。
令p为样件数、o为操作员数、r为每格重复数，MS为对应均方。
重复性方差 = MS_误差。
操作员方差原估计 = (MS_操作员－MS_交互)/(p×r)。
交互方差原估计 = (MS_交互－MS_误差)/r。
样件方差原估计 = (MS_样件－MS_交互)/(o×r)。
四个原始矩估计保留；参与呈现与合计的分量取max(0,原估计)。再现性=操作员＋交互；GRR=重复性＋再现性；总变异=GRR＋样件。
SD=方差平方根；研究变异=6×SD。
方差占比=分量方差/总方差×100%，四个基本分量可合计100%，合计项不再相加。
研究变异占比=分量SD/总SD×100%，各项不能相加作100%。
公差占用=6×分量SD/(USL－LSL)×100%，它不等于方差占比，也不直接成为产品合格判定。
总方差为零时占比为空，暂停资格解释；数值尺度无法有限呈现时不输出失真结果。
始终保留交互，当前不提供P/F检验、置信区间、ndc、自动合并交互、属性一致性、嵌套/破坏性、偏倚、线性及稳定性分析。需要进一步方法评审，不能声称与默认Minitab自动选型完全相同。

全试验来源摘要包括方案、成员、观测、配置、SN、人员、规范、仪器、设备及相关校准登记；绑定原始导入行ID和资料版本。600秒凭据绑定试验、截止、规则及当前账号，资料/规则/权限变化后重新读取。
逐点显示方案、对应成员、SN/工号、规范、所引校准及该观测的Excel文件/工作表/行号。归档原件按当前原件权限检查；能看到业务读数不自动取得全工作簿权限。
完整CSV导出全部已登记观测，包括不适用和重复，保留原数值、单位、原因及Excel来源，防止公式注入并记录导出审计。普通读取不新增事实、审计或账号状态。
本专题未新增团队共享、个人MSA快照、自动通知、批准、源系统写回或真实设备接入；既有SPC个人快照和发布指标保持原样。

后续真实试验要先确认样件覆盖实际产品变异、操作员代表性、方法/夹具、盲测与随机顺序、重复读数独立性、环境控制、仪器分辨率与适用模型；无法重复测量的试验须使用另外的设计。没有可靠依据不设置MSA合格阈值。
