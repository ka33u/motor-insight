# BI跨专题探索

从任一专题完成当前范围计算后，点击“跨专题探索”，选择另一个可访问专题。弹窗先显示每张目标分析卡的日期角色和条件适用性，再选择进入方式。

| 方式 | 保留条件 | 清除条件 | 进入要求 |
|---|---|---|---|
| 完整继承 | 当前与对照范围、两侧名称、所有直接身份联动 | 无 | 全部目标卡支持；使用日期时来源和目标日期角色集合一致 |
| 保留当前对象，重选日期与对照 | 当前产品族、客户；全部直接身份联动 | 当前日期、整个对照范围、两侧名称恢复默认 | 存在可保留对象，且全部目标卡支持这些条件 |
| 开始新范围 | 目标卡自己的模型与固定条件 | 所有临时范围、对照、身份联动和自定义名称 | 目标专题可访问；不可用卡仍会暂停 |

例如，从“装配日”口径转向“检测发生日”口径，不能直接把日期范围照搬后声称样本相同。可以保留当前配置或SN，但只有目标每张卡都声明支持相应直接身份时才允许；否则需要明确开始新范围。系统不会按相似名称猜关联。

当前对象模式不保留原对照的产品族或客户。直接身份联动原本同时作用于两侧，保留后也不会变成隐含的另一份对照。全部目标卡仍叠加自己的局部条件、已发布指标及字段权限；继承条件不保证有结果。

进入后通过“返回原专题与范围”恢复跳转时已应用条件，返回的是临时分析。不会更新原个人视角、工作页布局、结果快照、模型或业务事实。结果重新读取当前已导入数据，所以返回时的数字可能随数据更新而变化。

临时路径只在当前浏览器标签页有效，最多20条，每条2小时。预览需在10分钟内确认；条件、访问权限、模型、指标或规则变化会要求重新预览。刷新带探索路径的页面会恢复该路径的起始范围，后续条件调整可另存个人视角。URL只保存随机路径编号，条件凭据保存在当前标签页；复制链接到其他标签页不形成共享分析。

日期角色一致只是继承条件的门槛，不证明跨专题样本相同、单位可加或存在因果关系。仍须核对每张卡的对象粒度、样本、时间含义和Excel行来源。

当前全部业务事实为合成Excel演示数据。服务端、原生HTTP和纯JavaScript状态/呈现检查见版本记录；浏览器实际渲染、手机、键盘和实际下载尚未验收。任意跨表关系推断、多值刷选、共享探索路径与真实U8/MES接入仍待建设。
