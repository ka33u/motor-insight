BI个人受控试验：视角定义、冻结结果与当前资料核对（2026-10-07）

1. 定义与呈现
个人视角保存“怎样分析”：自定义编码、名称、说明、试验身份、固定采样计划、产品规范、规则版本和摘要、业务截止、显示小数位及产品公差开关。更新形成版本，过期版本不能覆盖新版本。基线由来源试验声明，不能在显示条件中重选或隐藏异常后重新拟合。
冻结快照保存“当时看到什么”：全部观测、计算结果、缺口与不适用原因、引用字段、旧Excel导入行身份、源文件摘要和当时规则文本。保存的是整个试验；翻页不缩减快照。快照不可覆盖，原视角编辑或归档不会改写它。
读取顺序：身份/版本与创建时刻→业务截止与资料适用性→基线和监控结果→两图/观测→旧来源→当前资料核对。视角与快照分开标明；缺失不填0，公差和控制限分开。

2. 操作入口
http://127.0.0.1:8765/#spc-workspace
在“过程稳定性试验”点“保存个人视角”，填写本人唯一编码、名称及保存依据，可关联一个可读专题。保存后“当前结果”按固定定义读取当前资料；采样计划、规范或规则变化时暂停，核对后更新版本或另存。
点击“冻结”读取完整试验并保存不可覆盖快照；在快照中逐点查看旧Excel行引用、导出完整CSV或包含来源和规则文本的JSON。“刷新快照凭据”仍读冻结内容，不重新计算为当前资料。
专题的“我的受控试验与冻结结果”列本人关联内容；该试验仍使用独立固定采样计划，通用专题日期条件和卡片联动没有应用到它。关联动作不更改共享专题布局，不向别人共享内容。

4. 当前资料核对
只核对冻结时与当前的同一试验身份，按观测ID对应；更正、新增、当前缺失和来源版本变化分列。不生成删除对象的0值。
定义变化：采样计划、规范或规则不同，不作同口径差值判断。
基线资料更正：显示冻结和当前两组控制限，保持旧快照不变，避免把重新计算的限值误当作改善。
仅监控资料更正：可保持原基线，指出观测和信号变化。
资料相同：说明观测和计算相同；来源摘要单独显示，来源版本变化不等于生产变化。当前试验不存在时冻结结果仍可读取，不补造当前结果。

5. 权限与来源
仅创建者读取；仍检查当前账号角色、来源字段和关联专题的访问权。敏感金额不写入这类试验快照。停用、会话版本变化、权限或快照内容变化会阻止沿用旧凭据。
逐点来源使用创建时的源行身份；不跟随当前Record来源指针。原始Excel下载需有当前导入原件权限，并校验旧批次、行与文件字节；快照不额外授予原件访问权。
读取不写业务事实；视角、快照、归档与导出记录审计。重复申请不重复写入，审计失败回滚操作。演示上限每人100视角、100快照，单快照20MB。
