BI过程稳定性：定义、呈现与受控合成试算（2026-10-07）

1. BI要回答什么
BI把来源事实按固定口径转为可核查的结果、解释、对象与调查线索。产品是否超限、过程是否有控制图信号、测量系统是否合格、是否批准放行是不同判断。

2. 本次可运行的范围
受控采样试验、观测、过程事件三张标准Excel表：10个独立合成试验、730条观测、10条事件，共750行，已使用标准导入服务加入演示库。复用现有配置、规范、设备与SN；旧测量数据不补造顺序，首检、复测与放行事实不重写。
主库累计213,441条事实、115类有数据的原始契约、48个导入批次。第32号字段映射工作簿仍只用于核对，没有业务导入；因此34编号不等于34份已导入工作簿。

3. 怎样呈现
试验身份与方法 → 资料检查数量 → I单值图与MR相邻移动极差图 → 基线/监控信号分列 → 观测清单 → Excel文件/工作表/行号与完整CSV。
产品公差与控制限用独立线型；序号缺号、缺测、作废、重复或待核对点断开MR。原始数值可核对不代表整体方法已经适用。二值项目只展示0/1计数，顺序未知不按Excel行号绘制连续过程。
每个试验声明固定基线末序号。翻页、隐藏产品公差或导出不重新拟合基线。20点是本项目试算门槛，不是NIST规定或过程稳定性的证明。

4. 口径与模型
当前只检验单点严格越过控制限；MR取相邻适用序号的绝对差。I中心=固定基线均值，I控制限=均值±3×MR均值/1.128；MR下限0，上限3.267×MR均值。负数控制限不裁成0。
控制信号用于调查。测量系统、样本独立性、工况和基线尚未工厂审定，没有Cp/Cpk结果，不自动批准质量、放行或发货。新增模型规则版本SPC-I-MR-TRIAL.01；原52个保存模型及交付v8发布指纹保留。

6. 来源与权限
图、表、下钻和CSV使用同一试验。签名凭据绑定账号岗位/权限版本、来源与模型版本，600秒过期；变化后重新读取。读取接口不增加业务事实或审计，导出另记审计。
六岗位可读取非财务试验资料，产品/设备金额按岗位过滤；Excel归档原件沿用管理员导入权限，不因图表读取而扩大原件权限。
