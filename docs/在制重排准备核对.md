# 在制重排准备核对

入口：**在制重排准备**（`#wip-readiness`）。适用对象为计划、车间、工艺、仓储岗位，先核对一张工单有哪些已导入证据，以及还缺哪些资料才能计算剩余工序。

本页使用已通过 Excel 正常导入的合成数据，不连接 U8/MES，不写回工单、库存、计划或批准结果。此页只建立资料核对入口，**不自动计算在制剩余工序排程**。0.36.0新增[在制剩余试排](在制剩余试排.md)，仅对另行导入、明确任务映射的完整模拟方案计算。

## 三种数量分开阅读

| 证据 | 阅读粒度与定义 | 不能由此推断 |
|---|---|---|
| 报工 | 按原报工记录分类为已结束时间登记、截止时未结束、未来登记、时间待核对；逐笔保留投入/良品/报废/返工 | 不跨工序累加良品数，不把报工笔数当作已完工任务数或电机台数 |
| 在制 | 按原生产批次份额核对，定子与转子分别列件数；混箱保留本原批份额及整箱数 | 不将定子加转子得到电机台数，不累加重复展示的整箱量，隔离/返工位置不等于可投入 |
| 领退料 | 复用原备料定义，按工单BOM、原单位列整单定额、累计领料、关联退料、净领料、整单待领 | 净领料不等于线边实存或实际消耗，整单待领不等于剩余工序耗料，不按报工良品或装配SN虚构扣料 |

报工缺明确路线行号。当前配置版本的同名路线仅列为候选，即使只有一个也不会自动绑定；工单批内份号、分支、历史版本和返工归属仍需明确。时间分类依据开始/结束时点，旁列原状态；原状态写“完成”而结束在截止后时，仍归入截止时未结束。

在制批次缺有效基准或存在错误时，完整分支数量留空，另列已知部分和未知批次数。一个分支没有已登记原批次也不判为零在制。装配SN只计截止前、配置与工单相符的记录，错误资料单列；报工、在制和SN不能互相替代完整性证明。

原备料已排除完工或取消等工单时，本页显示“整单待领未计算”，不补零。物料明细保留原计算问题和提示，本页没有重新试配物料池或占用资源。

## 时点、筛选与来源

固定业务和登记截止均为 `2026-10-01 18:00:00`；这不是当前电脑日期。仅在制基准及流转按双时点选择版本，其余主数据、工单、报工、SN和订单关系采用当前已导入记录，不构成全厂历史数据库快照。

顶部卡片和按登记状态的并列图使用完整应用范围。下面的分类按钮筛选工单清单、下钻及导出，分类可交叠；有报工和有在制份额不能相加为工单总数。“未结束”表示登记时间在截止时尚未结束，不证明机器正在运行；零记录也不证明从未开工。

详情按工单并列待补依据、原批次位置、报工原行、领退料及SN。混箱来源补齐关联其他根批次的基准与流转，而不是将整箱数量归给当前工单。物料核对来源包括相关库存批次台账与必要采购、状态证据。点击来源可查看Excel文件、工作表及行号，原件下载保留管理员权限。

CSV导出全部符合当前清单条件的工单，不受页码裁剪；包含分支、根批次、位置、报工、SN、领退料、问题、待补依据及去重来源。来源、范围或计算定义变化后旧回执失效；成功导出按实际文件字节摘要记录审计。六种现有读取岗位可查，不返回价格、工资或人员成本。

## 0.35.0历史快照与后续衔接

0.35.0发布时沿用46份有效初始化Excel（保留47份原工作簿）、234,037条事实，没有新增或修改业务输入。312张工单中，200张有截止前报工；119张在制位置资料不完整。当前截止下没有已核定的正数在制份额；这不能推断现场没有在制实物。

0.36.0的48号工作簿已在两张模拟工单上按以下结构补齐。其他工单仍需逐一完成版本化输入：

1. 工单、批内份号、路线任务、报工的明确映射与完成/返工归属。
2. 剩余任务数量、剩余工时、前序完成时点及最小等待约束。
3. 线边实盘、批次状态、实际耗用及剩余工序需求，防止重复预留已耗材料。
4. 在加工任务的人机占用、预计释放及中断恢复/换型条件，防止重复安排同一容量。

这些能力仍待建设，原“整批未开工”基线门槛和独立联立试排保持原定义。
