# 物料、人机联立试排

入口：平台侧栏“物料人机联立试排”（`#joint-schedule`）。本页用合成未来假设演练计划，不批准派工，不写回库存或计划。

## 阅读顺序

1. 选择物料方案及派序策略，检查时间范围、人机方案和假设版本。
2. 先看完整批次的完成、未排入和晚交；资料不足时整案暂停，不显示健康的零延误。
3. 在设备/人员甘特和全部任务表中找首个阻断任务，再下钻用料、预留、资格与来源。
4. 切换“物料与预留”，核对需求、供给批次、FIFO流水及数量守恒。完整CSV/JSON包含暂停方案的原始假设。
5. 使用[两种派序对照](联立试排策略对照.md)并列核对同一假设下的批次取舍、任务阻断与预留变化；保持原算法及全案来源。

## 计算口径

- 每个未来批次使用当前配置的BOM版本；这不是订单冻结BOM。所有用料行必须显式绑定到同产品、同分支、同路线版本的工序。
- 整批需求 = `ceil(批量 × BOM单耗 × (1 + 损耗) / 步长) × 步长`。演示kg步长0.001、件步长1；不同单位不相加。
- 绑定工序第一个按派序成功排入的任务，在准备开始时预留整批用料。同工序后续份号不得早于该预留时点开始；这是保守的整批备料假设。
- 同物料、同单位的供给在方案内共享，按可用时间、供给编号FIFO，允许拆分供给批次。隔离批次全部排除；其他批次扣除其中不可预留量，不重复扣减。
- 先证明物料足够，再选择设备、人员、资格与日历的共同连续窗口；成功安排才提交预留。失败候选不占料。
- 每任务一人覆盖全部换型和加工，设备和人员容量均为1；同时考虑前序及滞后。使用尾部追加启发式，不回填空档、不证明最优。策略切换会重算全部任务。
- 按派序先占供给，可以先预留未来物料。后续任务不抢占已预留数量，即使其可开始时间更早。未排完批次的已有预留保持，不自动释放。
- `可用供给 = 已预留 + 剩余`。总量缺口仅比较同物料同单位的全部需求与试排范围内供给，不等于时间齐套；总剩余列包含范围外到料。
- 物料就绪等待、共同等待和人机参考完成差值回答不同问题；等待不能相加，参考差值不作因果解释。

## 权限与来源

管理员、分析师、运营可查看；其他角色不能通过原始记录接口绕过。结果、任务、来源分页和导出绑定同一方案、策略、源记录、规则及账号权限，有效期10分钟；过期或依据改变须重新计算。原件下载权限另行检查。

公开导出保留物料、人员、设备输入、BOM和最小必要档案字段、来源行与摘要；不附带活动凭据或价格字段。成功导出写入审计，不修改业务事实。
