# 我的工作台

工作台把日常使用的分析与核查入口排在一起。它保存本人导航偏好，打开后仍由原页面读取当前资料、应用原有口径和权限。业务数据均为模拟Excel导入；工作台不接入用友U8或MES。

## 使用方式

1. 从侧栏进入“我的工作台”，点击“添加入口”，按类型、名称或编号查找目标。也可在已有页面点击顶部“收藏当前入口”。
2. 给收藏设置容易辨认的本人别名和工作分组，例如“早会核查”“车间跟进”。同一目标只保存一项，每账号最多100项。
3. 用卡片上的上下按钮调整组内顺序，用分组标题上的按钮调整组序。空分组显示为“未分组”。
4. 点击“打开”进入当前页面；“打开核对”进入原有的定义或绑定核对流程。目标不可访问时，卡片不提供跳转。
5. 可将整个工作台或一项当前可用的收藏设为登录入口。只有登录时地址中未指定页面才应用此偏好；已打开的具体地址优先。失效或待核对的登录收藏回到工作台并提示。

“整理”可以改本人别名、分组、登录偏好或移除收藏。移除不删除原模型、专题、视角、口径卡、编码规则或业务资料。多个标签页同时修改时，过期修订会被拒绝，刷新后再整理。

## 可以收藏什么

| 类型 | 打开的位置 | 状态依据 |
|---|---|---|
| 系统页面 | 已有固定模块 | 与当前侧栏相同的岗位访问规则 |
| 分析模型 | 自由分析中当前模型 | 可见性、数据集与字段权限、当前定义 |
| 分析专题 | 当前专题 | 当前可见专题和各卡片可用状态 |
| 个人视角 | 原专题与保存的本人视角 | 本人所有、未归档、绑定是否需要重核 |
| 个人专题页面 | 正常页面，或待核对时的定义页 | 本人所有、版本及专题/模型绑定 |
| 个人口径卡 | 口径卡详情 | 本人所有、当前模型定义与复查日期 |
| 编码规则 | 当前规则与记录 | 规则当前版本、启用或停用状态 |
| 试排与基线方案 | 原方案及明确策略/阅读方式 | 当前权限、方案记录与Excel来源完整性；不是计算状态 |

目录不列其他账号的个人视角、页面或口径卡，管理员也不能通过工作台目录代读这些内容。配置变更按既有管理员审计权限记录账号、修订和个人配置；读取及打开不新增使用次数或访问轨迹。

## 方案收藏（v0.30.0）

“添加入口”选择“试排与基线方案”，可按原编号、名称或阅读方式查找。资源试排、人机联立各有两种单策略；物料联立另可收藏两种派序对照；订单基线另可收藏两种冻结BOM假设试排。已在页面明确选定方案时，顶部“收藏当前入口”识别该方案和阅读方式；原模块入口收藏继续保留，未指定方案的模块地址仍只收藏模块。

目录完整分页，不因只显示第一页而遗漏方案。目标由方案族、本库记录号和阅读方式组成；原业务编号不改写，前导零保留。两策略对照不依赖返回时的单策略偏好，同一对照只收藏一次。临时读取凭据会丢弃，未支持的附加条件不会被悄悄保存。

卡片显示当前方案名、声明版本和记录修订；本人别名保留。方案正常导入更新后打开当前资料，来源身份损坏或目标删除/失权时通用显示不可用。此处只核对导航入口，不在加载工作台时运行排程，因此“可打开”不表示资料全部通过、可排、最优或已批准；具体状态在原方案页面核查。

收藏内部号只适用当前数据库，完整数据库重建后不能把个人配置直接跨库搬用。不在初始化时自动为用户设置方案收藏或登录偏好；演练只在隔离模拟库操作。

## 范围与结果如何保存

收藏只保存目标引用、本人别名、分组、顺序和登录偏好。不会把任意URL、临时筛选、分析数字、浏览路径或原件读取权复制进工作台。常用筛选先在专题中保存为个人视角，再收藏该视角；定义变化后沿用原有重核机制。

收藏模型指向当前模型，不冻结历史版本。卡片显示当前名称和版本；本人别名保留。目标删除、归档、撤销权限或定义不可用时显示通用不可用提示，不展示新获取的受限名称。浏览器中已经读到的内容无法通过后来撤销权限收回。

## 升级与接口

旧库先备份，再执行 `.venv/bin/python manage.py migrate --noinput` 并重启。迁移0023新增两张个人配置表，不迁移业务事实，不为已有账号自动创建收藏。当前新建演示库仍通过43份有效Excel正常导入事实，个人工作台从空白开始。

| 接口 | 用途 |
|---|---|
| `GET /api/workbench` | 本人收藏、当前状态与修订 |
| `POST /api/workbench` | 添加、整理、移除、完整排序、设置登录入口 |
| `POST /api/workbench/catalog` | 按类型、名称或编号分页查找当前可选目标，每页25项 |
| `POST /api/workbench/trial-target` | 按原方案编号、页面和阅读方式核对固定内部目标，不写入配置 |
| `POST /api/workbench/open` | 按收藏编号与修订重新核对并返回内部目标 |
| `GET /api/workbench/start` | 无指定地址时的本人登录目标 |

所有接口要求登录，写入要求CSRF校验，成功响应禁止缓存。请求字段严格核对；条件放在正文。单类可见候选超过2000项时暂停目录读取并提示整理，不截断冒充完整目录。当前工作台只选择八类固定内部目标，不支持外部链接。

## 验证与边界

初版22项服务端用例覆盖七类目标、六岗位隔离、私有目录、定义漂移、权限撤销、归档、冲突、回滚、上限和接口约束。纯JavaScript检查覆盖分组与转义、异步旧响应、连续打开、离开页面、选择器和登录地址优先级；这不等于浏览器渲染验收。完整回归、公开Excel全新回放、升级保留检查及六岗位原生HTTP另见仓库验证记录。

当前未提供对象收藏、共享工作台、角色预置模板、订阅提醒、收藏结果导出或使用效果统计。真实岗位试用、浏览器、手机与键盘操作仍需验收。X-21标记为模拟部分覆盖。

v0.30.0新增20项服务端与13组纯JS检查，覆盖四类方案、11种类型/阅读方式组合及来源/权限/旧响应边界。六岗位原生HTTP验证完整目录、保存重开、原目标页面读取、登录回退与移除；完整检查见 `demo/validation.json`。浏览器渲染、键盘和手机仍未验收。
