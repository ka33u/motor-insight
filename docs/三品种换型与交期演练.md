# 三品种换型与交期演练

`MP-261016-001` 用同一份模拟输入比较两种现有派序。准备时间减少120分钟，但B002晚交，整个方案也晚结束6.6分钟。这个例子用于核查多品种生产的取舍，不是最佳排程建议。

## 在BI中阅读

1. 打开“物料人机联立试排”，选择`MP-261016-001`，进入“两策略对照”。三批原数量只计一次；先看每批完成状态和时差。
2. 打开“人机占用对照”，同一原设备或工号上下两行共用时间轴，浅色准备、深色加工。点任务查看原方案依据，点对象联动完整任务列表。空白不代表可插单。
3. 在物料页核对需求、整批预留及批次获料。此例没有短缺，不能把晚交归为缺料。共同来源可追到Excel行，完整导出保留输入和两列结果。
4. 可以收藏此明确方案的两策略阅读入口。顶部的晚交状态仍按各批内部目标判断，收藏不复制结果或批准方案。

当前界面已有逐任务准备时长及占用分段；上表的首次/跨族准备汇总由验算和说明给出，尚无单独的准备次数汇总卡。这个边界避免把文档结果误称为已交付的新BI组件。

优先级显式人工给定，恰好令两个A族产品相邻，并非系统自动寻找同族顺序。现有启发式无抢占、无回填空隙、无具体型号转换矩阵、模具约束或最优性保证。此样例说明少准备不保证交期和总结束时间同时改善；它不是企业实际改善收益或因果结论。
