电机制造企业：BI分析方法、页面预演与数据门槛
bi-method-workshop-20261007

BI是一套按岗位提供决策支持的数据服务：把业务事实、统一指标、分析方法、来源证据和处理复查组织在一起。页面是使用入口，口径和模型是可复用定义。
18类方法是选型建议。全部382项仍是候选需求，63项指标与17页保留；方法推荐不表示算法已实现、字段已齐、口径已批准或需求已验收。
适用：U8、momo MES待上线；约900台/日、全流程自制、小批量定制；预算和IT人员有限。
首批建议：订单交付P02、质量试验P05、对象履历P06、数据可信P15。先核对真实样本，再逐部门扩展。
一期不以凑齐382项为目标；需求先按适用、来源、决策价值和维护负担评审。

一、六项数据门槛
对象与应有范围｜核实：一行是什么；有哪些对象应被纳入；唯一键与关系依据是否完整｜不足时：对象或关联未知时，展示待核对清单，不虚分订单数量。
数值、单位与测量｜核实：原值、标准值、换算、仪器、方法、工况和有效版本是否一致｜不足时：混合单位/方法暂停合并；缺项不补零。
时间与真实顺序｜核实：事件、登记、截止、目标期间、采样顺序及迟到修订各指什么｜不足时：缺事件历史不能回放；同刻无顺序不能自行生成移动极差。
抽样、复测与可比性｜核实：首检、首次完整、最新、全部会话如何选；配置、批量与环境能否比较｜不足时：筛设备后不能将复测重称首检；选择偏差与排除数量显式显示。
模型假设与基线｜核实：算法适用条件、独立性、基线、规则、训练/回测及不确定性是否有依据｜不足时：描述性资料只支持描述；稳定性、能力、预测及优化分别核实。
责任与复查｜核实：谁读、何时用、下一步怎样查证、谁维护、怎样验收｜不足时：无使用者与维护责任先保留候选；分析建议不自动执行业务批准。

二、18类分析怎样定义和呈现

QUEUE 截止队列与优先事项
问题：现在应该先处理哪些对象？
必需资料：唯一业务对象；有效状态事件；约定期限与时区；责任与处理依据
算法/定义：按统一截止重建互斥状态；已知未完成与资料未知分别计数；影响与到期分别排序，不编造综合评分。
呈现：3个状态摘要＋期限分布＋条件矩阵＋对象表
进入条件：完整的应有对象集合和生效状态；截止型结果保留截止时点。
暂停与边界：无事件历史不能倒推历史状态；没有期限不称逾期。
需求示例：C-02/M-01/W-02
分析选型与呈现建议；不是已上线算法或已审定业务口径

TREND 趋势与可比期间
问题：变化发生在何时、是否持续？
必需资料：事件时间与登记时间；完整业务日历；期间完整度；稳定指标版本
算法/定义：按固定业务日期归期；空记录、真实零、未覆盖三种情况分开；同比环比只用完整且可比期间。
呈现：折线与缺失断点＋样本/覆盖条＋变更标记
进入条件：先明确事件量、余额、到期队列属于哪类时间口径。
暂停与边界：五天资料不能填满年度曲线；余额不跨日求和。
需求示例：A-03/G-03/T-01
分析选型与呈现建议；不是已上线算法或已审定业务口径

TARGET 目标与偏差
问题：结果偏离了哪个已确定目标？
必需资料：目标对象与版本；上下限或方向；目标期间；同范围实际与依赖版本
算法/定义：同范围比较实际和目标；比例从分子分母重算；总目标不自动按销量分给部门或配置。
呈现：实际/目标条＋偏差排序＋版本与覆盖
进入条件：确认目标来源、批准责任、单位和是否允许提前预警。
暂停与边界：无目标显示待设定；假设目标明确标注试算，不生成正式绩效灯色。
需求示例：A-01/A-07/X-20
分析选型与呈现建议；不是已上线算法或已审定业务口径

BRIDGE 差异桥与结构分解
问题：差额来自量、价、结构还是核算变化？
必需资料：两侧完整范围；同税价币种单位；成本/价格基准；分解次序和交互项
算法/定义：固定分解顺序并显式保留交互项和未解释差额；各部分与总差额勾稽。
呈现：瀑布桥＋配置结构对照＋差额明细
进入条件：真实收入和成本按同一结账版本核对，估算与实际分列。
暂停与边界：分解不是因果证明；没有分摊依据不能把共享费用精确摊到SN。
需求示例：A-09/R-02/T-14
分析选型与呈现建议；不是已上线算法或已审定业务口径

FLOW 流转、等待与资源
问题：工单或批次卡在哪里，影响哪个订单？
必需资料：流转事件和位置；拆合批份额；投入产出单位；资源日历及有效占用
算法/定义：按部件层次和单位核对投入、耗用、在制、返工、报废；自然等待与实际作业时长分别汇总。
呈现：工序状态矩阵＋位置/等待分布＋资源时间轴
进入条件：定子、转子、整机分别计量；合箱保留各工单份额。
暂停与边界：没有事件不能把计划任务当在制；资源高负荷不直接判定系统瓶颈。
需求示例：G-02/G-09/F-02
分析选型与呈现建议；不是已上线算法或已审定业务口径

TRACE 对象履历与影响反查
问题：对象从哪里来、还影响谁？
必需资料：稳定身份；关系依据与有效期；拆换沿革；原件指纹和授权
算法/定义：只沿有证据的关系连接；唯一SN去重；确认影响、候选影响、断点分别呈现。
呈现：对象时间线＋有效关系树＋影响清单＋证据抽屉
进入条件：查号从内部ID映射到显示编码，原件权限独立核验。
暂停与边界：名称、时间接近和文件名均不能自动证明订单关联。
需求示例：N-01/N-03/N-12
分析选型与呈现建议；不是已上线算法或已审定业务口径

DIST 同配置分布与裕量
问题：数值集中在哪里，哪些观测接近规范边界？
必需资料：配置和规范版本；特性数值与标准单位；会话及复测身份；方法与工况
算法/定义：先按SN选择约定会话，再按方法/设备筛选；从有效原始值重算分位数，展示排除及样本数。
呈现：直方图/箱线＋规范限值＋温度/设备分层＋样本表
进入条件：同配置、特性、规范、单位与方法；首次事件、首次完整及最新结果分别命名。
暂停与边界：分布不证明稳定；不同单位和复测择优不能混合；二值项目用计数。
需求示例：M-03/M-09/M-15
分析选型与呈现建议；不是已上线算法或已审定业务口径

SPC 过程稳定性与控制图
问题：固定过程中的波动是否出现需调查信号？
必需资料：可核验采样序号或唯一时间；同配置工序特性及测量条件；子组策略；固定基线与规则版本
算法/定义：先确定单值、合理子组或计数模型。单值I图的候选界限为均值±3×平均移动极差/1.128；移动极差须来自真正相邻观测。基线固定，不随筛选重拟合。
呈现：基线/监控分区＋I与MR双图＋规则信号＋变更事件＋原观测
进入条件：测量系统及采样方案核实；同刻无采样顺序、缺失、换型、失准及自相关须先处理。
暂停与边界：控制限和产品公差分开；序号不是SN字典排序或Excel行序；有信号是调查线索，无信号不等于稳定已获确认。
需求示例：L-06/L-13/H-01
分析选型与呈现建议；不是已上线算法或已审定业务口径

CAPABILITY 过程能力适用性
问题：经核实稳定的过程对规范有多大余量？
必需资料：已核实稳定性；有效规范限值；测量系统证据；独立样本与分布假设及估计方法
算法/定义：双侧规范的Cp=(USL−LSL)/(6σ)，Cpk取两侧标准化余量较小者；声明σ估计依据、期间及不确定性。单侧规范另定，不能虚造另一侧。
呈现：适用性门槛＋规范/分布＋估计值及区间＋样本证据
进入条件：过程、测量和抽样条件确认后才估计；样本方案由质量岗位审定。
暂停与边界：无稳定性或分布依据不显示正式Cp/Cpk；不凭统计指数自动放行。
需求示例：L-06/L-13
分析选型与呈现建议；不是已上线算法或已审定业务口径

MSA 测量系统与检验一致性
问题：差异来自产品、仪器、方法还是判定者？
必需资料：预设重复测量方案；样件与操作者；仪器/方法版本；随机化和重复次序
算法/定义：按重复性、再现性、偏倚/线性/稳定性或属性一致性选择方案；校准证书与MSA结论分开。
呈现：样件×人员×重复矩阵＋变异分解/一致性表＋方案原件
进入条件：有计划的重复实验与适用公差；普通生产复测不能自动充当GRR研究。
暂停与边界：校准有效不等于测量系统能力已验证；无研究方案只显示缺证。
需求示例：P-06/M-13/L-11
分析选型与呈现建议；不是已上线算法或已审定业务口径

RELATION 关联线索与验证假设
问题：材料或工况差异是否与结果一起变化？
必需资料：可靠对象关系；双方可比单位；配置、批量与工况；缺失/排除及样本
算法/定义：先分层看散点和分布；记录候选解释、替代解释及需补的验证，不从相关性直接推断原因。
呈现：分层散点＋组内样本＋反例＋验证任务
进入条件：双方有唯一配对或经批准的汇总粒度，不做任意多对多拼接。
暂停与边界：记录时间相近不能替代批次关联；没有共同条件不作绩效排名。
需求示例：K-09/U-02/Q-09
分析选型与呈现建议；不是已上线算法或已审定业务口径

COHORT 队列成熟度与可靠性
问题：不同出厂批次在可比观察期内表现怎样？
必需资料：有效出厂/质保起算；观察截止；已失效与仍在观察；返修替换关系
算法/定义：按同起点和暴露年龄比较；未成熟与失访分列，必要时采用经审定的删失分析。
呈现：队列×观察龄期矩阵＋暴露样本＋故障/失访清单
进入条件：同配置和使用环境；质保起算及重复故障计数规则核实。
暂停与边界：未报修不自动等于无故障；新批次不能直接与多年老批次比失效率。
需求示例：U-03/U-07/U-11
分析选型与呈现建议；不是已上线算法或已审定业务口径

RECONCILE 数量金额与双来源勾稽
问题：哪一笔差额无法解释，需要谁补证？
必需资料：两侧对象键；有效截止与单位；核销/撤销记录；差额允许规则
算法/定义：一对多先按事实键汇总；匹配、差额、缺另一侧、未执行分别列出；允许差额有规则版本。
呈现：对账通过/未知摘要＋差异矩阵＋两侧记录和原件
进入条件：采购/入库/发票、库存/实物等各有独立口径与截止。
暂停与边界：没有执行对账不算通过；不把库存件数、公斤和金额直接相加。
需求示例：S-04/J-04/W-07
分析选型与呈现建议；不是已上线算法或已审定业务口径

FORECAST 预测与回测
问题：在有历史证据时，未来区间怎样估计？
必需资料：足够且可比历史；预测时点可用字段；训练验证切分；基准方法与回测误差
算法/定义：保留滚动时点预测，和简单基准在相同窗口比较；预测区间、覆盖和模型漂移一起呈现。
呈现：实际/历史预测对照＋区间带＋误差分层＋失效情形
进入条件：没有历史或预测时点可用特征时仅作条件假设，不称预测。
暂停与边界：五天模拟资料不支持真实需求或交期预测；未来结果不能泄漏到特征。
需求示例：B-06/B-10/C-04
分析选型与呈现建议；不是已上线算法或已审定业务口径

SCENARIO 假设情景与方案对照
问题：在同一基线下改变条件会怎样？
必需资料：冻结基线；参数和适用范围；明确约束；收益成本及未知项
算法/定义：只改变声明参数；显示差值、假设、不可行条件与未覆盖内容；实际和试算分开。
呈现：参数面板＋方案并排＋差异桥＋约束清单
进入条件：来源能支持模型关系，假设有版本和责任；不确定因素用范围表达。
暂停与边界：试算不自动改计划、报价或执行；缺约束时不宣称可执行或最优。
需求示例：F-06/S-05/R-12
分析选型与呈现建议；不是已上线算法或已审定业务口径

OPTIMIZE 有限资源方案优化
问题：给定目标和约束，哪些安排值得业务确认？
必需资料：资源/人员日历；路线先后；物料/换型；目标及罚则；求解边界
算法/定义：先检验可行性，再按声明目标比较；给出求解状态、时间限制、未安排对象和人工覆盖。
呈现：基准与方案时间轴＋资源冲突＋目标差异＋未排清单
进入条件：真实产能和任务约束标定；目标权重由计划与经营确认。
暂停与边界：未证明最优只称候选方案；合成900台/日不是工厂产能标定。
需求示例：F-07/F-12/V-07
分析选型与呈现建议；不是已上线算法或已审定业务口径

CURVE 曲线与过程区段
问题：设备曲线是否覆盖所需负载点或工艺区段？
必需资料：会话/批次；通道单位与采样时间；完整点序；规范及配方版本
算法/定义：保留原采样间隔及缺失，不用插值掩盖缺点；对齐依据、区段和限值各有版本。
呈现：原始曲线＋规范区段＋缺点标识＋同对象来源
进入条件：文件可解析且通道、订单/SN/炉批关联经过确认。
暂停与边界：一条终值不能生成整段温度曲线；不同负载/温度条件不直接叠图排名。
需求示例：H-27/M-11/M-16
分析选型与呈现建议；不是已上线算法或已审定业务口径

PARETO 缺陷与损失结构
问题：哪类问题影响范围大，先验证哪项改善？
必需资料：去重问题事件；缺陷分类版本；涉及SN及重复项；量或损失的归属
算法/定义：问题次数、受影响去重SN和损失金额分别计算；互斥分类才做累计贡献。
呈现：降序条形＋累计贡献（适用时）＋对象及分类未决项
进入条件：明确一机多缺陷和同问题重复登记规则，不直接相加当总台数。
暂停与边界：没有成本证据不把次数当经济损失；未知原因单列。
需求示例：L-02/O-02/U-05
分析选型与呈现建议；不是已上线算法或已审定业务口径

三、17页的阅读和下钻预演

P01 经营决策总览｜总经理、经营会
问题：今天有哪些交付或质量问题需要跨部门协调？
方法候选：目标与偏差 / 差异桥与结构分解
主结果：按期足量交付率 OTIF / 首检合格率 FPY / 订单毛利率
解释：交付与质量趋势；目标差异条形；配置结构变化
对象：影响最大的订单、质量批次和资金事项，显示责任与证据
路径：总览 → 责任专题 → 订单/批次 → 原件
决定：安排协调事项并复查上次承诺
门槛：目标有版本；财务有结账口径；缺指标显示待补数据
手机：关键结果与5项重点异常
无数据：结果未具备则显示具体缺口；不补零，不自动亮绿，不以模拟值填真实经营页

P02 订单交付指挥页｜销售、计划、车间
问题：哪些订单可能晚交，具体卡在哪个条件？
方法候选：截止队列与优先事项 / 流转、等待与资源
主结果：逾期未交量 / 未交订单量
解释：订单行×开工/工序/检测/证明/发货条件矩阵；交付时间线
对象：订单号、配置、承诺日、缺口、阻塞对象、下一动作
路径：客户 → 订单行 → 分配工单/SN → 缺料或检测原件
决定：确认优先清单，协调缺料、排队或交期沟通
门槛：工单分配和SN归属明确；时间线不把推测当事实

展示/行动：期间选择器与比较口径提示；选择适合问题的观察窗口
X-36 异常状态机与跨部门转交｜数量金额与双来源勾稽 / 趋势与可比期间
前提：业务认可责任分工和关闭条件后启用；需建立对应身份、事件时间及有效版本
来源/粒度：异常规则、对象、责任记录、措施和复核证据；异常对象×状态事件
展示/行动：异常看板与转交时间线；防止无人接手或未经复核即关闭
X-37 数据分级与敏感字段最小展示｜数量金额与双来源勾稽 / 趋势与可比期间
前提：所有真实数据上线前需确认；策略设计不代表已实现细粒度权限；业务身份、生效时间、规则版本和来源原件可核对
来源/粒度：字段目录、敏感等级、角色范围和访问审计；字段×角色×使用场景×版本
展示/行动：字段分级目录与角色预览；确认岗位最小可见范围并验证导出一致性
X-38 需求适用性与暂不建设决议｜数量金额与双来源勾稽 / 趋势与可比期间
前提：暂无数据不等于不适用，决议不能自动改实施状态
来源/粒度：需求目录、评审结论及业务流程清单；需求版本×适用性决议
展示/行动：适用性矩阵；避免将全景目录直接变成开发清单
X-39 指标卡到业务动作的执行边界｜数量金额与双来源勾稽 / 趋势与可比期间
前提：查看或建议不能暗中写回ERP/MES
来源/粒度：页面定义、动作配置及权限审计；组件版本×动作定义
展示/行动：动作权限与前提清单；使使用者知道点击后会发生什么
X-40 分析配置发布前影响预演｜数量金额与双来源勾稽 / 趋势与可比期间
前提：历史已冻结结果不被新版本静默改写
来源/粒度：模型版本、依赖关系、同范围试算及评审；候选配置版本×依赖对象×试算范围
展示/行动：版本差异及影响清单；决定新版本是否可发布
X-41 指标不可比较原因直接说明｜数量金额与双来源勾稽 / 趋势与可比期间
前提：无依据不能生成调整后排名
来源/粒度：指标契约、维度关系、筛选及方法版本；两份分析范围×指标版本
展示/行动：可比性检查与修正提示；修正分析条件而非猜测原因
X-42 管理例会的数字故事与证据回放｜数量金额与双来源勾稽 / 趋势与可比期间
前提：摘要与原数据冲突要显式提示，不自动生成确定因果
来源/粒度：冻结结果、来源、注释、议题及行动；例会版本×结论组件×证据范围
展示/行动：可展开的例会阅读页；减少重复抄数并保留决策依据
X-43 页面内容密度与信息分层评审｜数量金额与双来源勾稽 / 趋势与可比期间
前提：点击量不等于业务收益，关键但低频功能不能据此删除
来源/粒度：页面版本、岗位任务、阅读评审及使用事件；页面版本×角色任务×评审
展示/行动：阅读任务评审与组件使用表；决定合并、隐藏或拆分页面内容
