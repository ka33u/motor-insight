# 订单与 BOM 基线核对

入口：`#order-baselines`。使用第40份自编模拟Excel，把独立试排批次映射到现有订单行、工单和分配记录，核对订单覆盖、用料版本及客户交期。没有连接真实U8/MES，也不写回订单、计划或库存。

## 页面如何读

1. 选择一个基线版本和试排策略。不同版本、不同方案的数量不能累加。
2. 先看订单覆盖。示例6条订单共135台，方案只安排50台，85台仍未覆盖。部分批次排完不能推导整单完成。
3. 看批次与订单、工单的映射，分别核对内部试排目标和基线客户承诺。客户原承诺保留在明细及导出中。
4. 看复制的BOM单耗、损耗、单位和取整步长，与当前来源及独立物料试排的需求逐项对照。
5. 查看差异、版本关系及Excel文件、工作表、行号。需要跨批次核验共享供给与人员竞争时，查看全方案来源或完整JSON。

基线资料有三种状态：`aligned`表示本次核对资料对齐；`review`表示存在来源变化或业务差异；`paused`表示完整性校验未通过。资料对齐不表示批准生产。暂停时不计算覆盖和用量，仍可导出原输入；待重核时保留独立批次试排时点，但不确认整单参考完工。

## 数量、日期与版本口径

| 对象 | 口径 |
|---|---|
| 唯一映射 | 每个试排批次恰好一条映射；相同订单跨批次去重，分配台数不能超出登记分配 |
| 订单基线 | 复制订单数量、原承诺和现承诺、工单/产品BOM与路线版本、工单状态及分配生效时点 |
| 基线BOM | 复制完整物料集合、单耗、损耗、单位、工序及步长，并核对内容与集合摘要 |
| 基线需求 | `ceil(安排台数 × 单耗 × (1+损耗) ÷ 步长) × 步长`；不同单位不得直接相加或默默转换 |
| 未覆盖 | 按基线截止时点重放登记发货，再以未发需求减本方案安排，最低为0；超排单列 |
| 整单参考完工 | 仅全部基线未发需求被覆盖、所有映射批次排完且资料无待核对事项时形成 |
| 客户交期 | 客户日期按当日23:59:59与加工完成比较；仅有完成时点的批次进入“交期后完成”分母 |
| 版本关系 | 同系列连续版本、前版引用、基线截止时间、行数及摘要完整；查看前版须打开其独立基线 |

全部日期沿用本地模拟业务时间，固定资料截止为2026-10-01 18:00。选中的6条现有工单均登记为未开工且没有单台或工序记录；在制、取消订单、跨订单分配和已登记发货超量等情况需要业务重核。

当前BOM变化不会替换基线用量。本功能用于对照：现有物料、人机联立试排仍独立使用其当前BOM输入，不会自动采用有差异的快照重新排程。摘要用于检测内容一致性，不构成不可篡改存证或历史签批证明。自编快照也不证明资料在模拟截止时点已实际存在。

订单与BOM字段为复制快照；登记发货则按时间重放当前来源，历史补录可能改变基线未发需求。来源变化会使旧读取凭据失效，必须重新读取。加工完成未包含检测放行、运输和签收，不能作为OTIF。

## 输入案例与权限

工作簿含10条基线、60条批次映射、539条BOM快照，共609行，经过正常Excel预览、校验及提交。四种资料对齐案例覆盖正常、晚到、缺料、缺人；其余案例覆盖摘要错误、漏BOM、重复映射、假设旧单耗、单位变化和断裂版本链。错误基线用于演练分析暂停或待重核，不会静默修正原始输入。

管理员、分析与生产岗位可读取；质量、财务及只读岗位不能读取包含人员试排依据的本功能及相应原始数据集。导出绑定账号、来源、计算规则和10分钟有效的读取凭据，并记录文件摘要。CSV含基线输入、结果及来源，JSON另含完整人机物料试排假设；两者均不导出读取凭据或财务价格字段。
