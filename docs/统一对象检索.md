# 统一对象检索

顶部搜索和“对象检索”入口统一查找销售订单、订单明细、工单、产品配置、整机SN、生产批次、周转批次、物料、客户、供应商、设备、工装、独立资源位、计量器具，共14类常用对象。

| 匹配方式 | 查找范围 | 用法 |
|---|---|---|
| 编码精确 | 完整主业务编号，区分大小写 | 核对标签或ERP单号；`000019`和`19`不同 |
| 编码前缀 | 原编码的开头，英文字母按数据库前缀匹配 | 查同一编码段；不改写返回的原编号 |
| 编码或名称包含 | 原编码以及明确列出的名称、型号、规格、容器号、资源位或客户采购单号 | 不记得完整编码时查找；命中字段会说明 |

不同业务表的相同编号会分别列出，不自动认定为同一对象。搜索结果按精确编码、编码前缀、其他包含匹配排序，每页25条，分页覆盖全部匹配记录。类型计数对应所有常用类型中的匹配，选定类型后显示其数量；数量是登记记录数，不是产量或跨表去重业务数。

对象详情提供三层信息：

1. **记录和来源**：原编号、业务表、当前记录版本，以及来源Excel文件、工作表和行。全部可见字段可展开；金额等字段继续按岗位过滤，原Excel下载仅沿用管理员导入原件权限。
2. **明确引用**：按字段字典声明的目标表及完整编号逐项查找。目标未导入和当前不可访问分别显示。被引用清单按业务表展示，一行多个字段指向同一对象时只列一次，并注明命中字段。
3. **业务解释**：SN可进入整机履历，生产批次可进入影响反查，订单行可进入交付核对。其他对象继续沿明确引用查找，不打开没有对应筛选的泛化看板冒充对象分析。

所有已导入版本都可能出现在检索及直接引用清单，包括未来、草稿、撤销和历史登记。这里没有按业务截止重放，也不替代各工作台的有效版本选择。引用计数不能证明当前有效、实际使用、质量合格或正式批准；没有找到直接引用，也不证明没有其他业务关系。

搜索和引用分页凭据有效10分钟，绑定账号、范围、字段规则和当前导入修订。资料、规则或权限变化会要求重新读取。搜索条件保存在当前页面运行期间，并按账号分开；完整刷新会清空。对象链接中的内部记录号只定位当前数据库，数据库重建后不能作为跨系统业务编码交换。来源中的原编号仍是核对依据。

材料批号与物料的复合身份仍从“批次影响反查”核对。本入口暂不覆盖跨系统编码别名、任意模糊关联、多跳影响计算、历史有效关系重放、全文附件或OCR。当前资料全部为合成Excel演示，浏览器、手机、键盘和实际下载交互尚未验收。
